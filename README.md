# Gesture-Recognition-Models

A gesture recognition project using computer vision and machine learning to control system brightness and volume with hand gestures. This project provides a hands-free interface to adjust system settings through real-time gesture detection.

## Features

- **Brightness Control**: Adjusts screen brightness using specific hand gestures.
- **Volume Control**: Controls system volume with gestures for quick adjustments.
- **Real-Time Screenshot**: Uses the camera feed to detect hand gesture and click the screenshot.
